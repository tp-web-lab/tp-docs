# Docutils reference sources

`demo.rst` and `roles.rst` are preserved verbatim from Docutils. Both explicitly state that their contents are in the public domain. The original attribution and copyright fields remain in each file; `provenance.json` records the source URLs, revisions and SHA-256 checksums.

`images/title.png` and `images/biohazard.png` are the assets referenced by the original demonstration, fetched from https://docutils.sourceforge.io/docs/user/rst/images/. They are copied to the generated examples so that image demonstrations work without relying on the remote server.

The generators adapt links, provide local dependencies for isolated examples, and group intentional errors separately. The original source remains unchanged. The adapted demo replaces quoted song/comedy extracts with short TP texts. The roles guide retains the native raw-role demonstration solely to document that feature; TP component examples use directives and roles directly.
