Extensions
==========

``tp-restructuredtext`` uses Docutils through Pyodide and adds support for TP web component directives and roles.

The component library provides controls, viewers and interactive activities that can be included in reStructuredText documents.

The detailed extension guide is being migrated. Consult the `library repository <https://github.com/tp-web-lab/tp-restructuredtext>`_ for the current reference.
