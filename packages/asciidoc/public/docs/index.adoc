= Introduction
:showtitle:

*tp-asciidoc* adapts https://github.com/asciidoctor/asciidoctor.js[Asciidoctor.js] for the web, with convenient support for TP components and standard HTML elements.

* link:base.adoc[Base] presents the AsciiDoc Syntax Quick Reference through editable examples.
* link:extensions.adoc[Extensions] is dedicated to the additional component and HTML syntax.
