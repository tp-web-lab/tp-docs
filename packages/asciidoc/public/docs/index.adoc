= Introduction

This is the new home for the TP AsciiDoc documentation. Migration of the full guide is in progress; the original repository remains the reference.

== Shared components

This documentation uses `tp-asciidoc-multi-pages`. Its `.adoc` pages are rendered by `tp-asciidoc` and can use the same TP web components as the other documentation spaces.

Use the sidebar to choose a page and the TP logo to return to the documentation portal.
