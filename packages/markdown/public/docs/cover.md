Yet another parser of Markdown!

{style="margin-bottom:1rem;"}

**tp-markdown** is an adaptation of [`markdown-it`](https://github.com/markdown-it/markdown-it) to make it easy to use **tp-components**.

{style="margin-bottom:1rem;"}

tp-markdown and tp-components are parts of the <tp-icon name="logo-tp" size=2em></tp-icon> web ecosystem, a colllection of web tools designed for creating **interactive technical documents for educational purposes**.
