CommonMark 0.31.2 — TP Markdown — Differences only

586/652 passed; 66 differences; 0 errors. Default TP configuration, using the official HTML normalizer.

This report contains only examples whose status is difference. Inspect all examples.

All 66 remaining differences in this corpus result from deliberate TP Markdown implementation choices: generated heading attributes, typographic substitutions, automatic links and YAML frontmatter recognition. They remain counted as differences in the strict CommonMark comparison; this does not imply full CommonMark conformance.

Every result below is static test output. Source and HTML are escaped and never executed.

Main types of differences

Each differing example belongs to exactly one row; the counts add up to 66. Mixed cases are identified in their descriptions. Classification does not change the official comparison or the pass count.

The largest groups concern attributes automatically added to the HTML, rather than the Markdown attribute-list notation. Attribute-only classifications are checked by removing just the named attributes from the normalized output and comparing again. The other cases have been reviewed; their classification is retained only while both HTML fingerprints remain unchanged.
