# Base: CommonMark

CommonMark defines the base syntax used by TP Markdown. The two sections below distinguish learning the syntax from checking the parser against the specification.

| Section | Contents |
| --- | --- |
| [Syntax](base-syntax.md) | The existing guide to CommonMark syntax, with 38 editable examples and links to the specification. |
| [Compliance](base-compliance.md) | Results from the complete official CommonMark test corpus, with expected and actual HTML for each example. |

The Syntax examples are a teaching selection. The Compliance corpus also covers edge cases and checks the HTML produced by TP Markdown with its default extensions enabled.
